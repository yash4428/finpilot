FinPilot: team guide

Everything you need to present the project, in simple words.

1. The idea

FinPilot is a personal-finance app with an AI assistant. It puts credit cards, loans, EMIs, spending, budgets, savings goals and tax in one place, and tells you how much money is actually yours to spend.

Problem: your bank balance looks big, but much of it is already promised to card bills and EMIs. People overspend, miss due dates and pay late fees. AI chatbots answer money questions with made-up numbers.

One line to remember: "FinPilot tells you what's actually yours to spend, and its AI never makes up a number."

2. How it's built

  • React website: what you see. It only talks to the Java backend.
  • Java Spring Boot backend: login, all money rules, daily 8 AM reminder job. Data is saved in PostgreSQL.
  • Python FastAPI backend: machine-learning models and the AI assistant. (Two backends were a course requirement.)
  • Google Gemini: the AI model that writes Pilot's answers. We use it as-is (no training).
  • Key idea: the AI never guesses numbers. It calls "tools" that fetch real data, and our code checks every number in the answer.

4. The wow moment: voice in Hinglish

Press the gold mic (bottom-right) and say: "Kya main dedh lakh ki bike le sakta hoon?" Pilot answers out loud ("Abhi nahi… 6 mahine ki no-cost EMI pe ₹25,000 mahina, wo chal jayega") and the dashboard strip turns red to show the shortfall.

Also try: "Mera bill kab bharna hai?" (bills glow) · "Tax kaise bachaye?" (opens Tax).

Mic not working? Tap one of the ready-made question buttons or use "Or type here". Same result. Voice needs Chrome, internet and mic permission.

5. Running the demo

  1. brew services start postgresql@16
  2. In the project folder: ./run.sh --seed (prints the link).
  3. Open the link in Chrome (usually localhost:5175) → "Explore the demo account" (demo@finpilot.app / demo1234).

No Gemini key, or Google busy? Pilot switches to offline mode automatically: same real numbers, simpler wording. Nothing breaks. No laptop? Present the slides; the script is in the speaker notes.

Quick live demo (3 moves): type 90000 in "Thinking of buying something?" → ask Pilot about the ₹1,00,000 laptop → say the bike question into the mic.

6. Likely teacher questions

Why two backends?Course requirement. Java keeps the records and rules; Python does ML and AI.
How does the AI not make up numbers?It must fetch numbers through tools, maths is done in code, and every number in the answer is checked. Wrong ones get the answer rejected.
Did you train the AI?No. Gemini is used as-is. We only use RAG (searching our 8 trusted documents, with citations) and tool calling.
Which ML models?Logistic Regression + TF-IDF (categories), Linear Regression (spending forecast), Isolation Forest (unusual charges).
Why no real bank connection?Needs an RBI Account Aggregator licence. CSV import is the legal alternative.
Privacy?Only card last-4 stored. Emails, card, account, PAN, Aadhaar numbers are masked before reaching the AI. Each user sees only their own data (JWT login).
How does it understand Hinglish?Our code converts phrases like "le sakta hoon" and "bees hazaar" into simple English meanings first.
Is it tested?Yes, 30 automated tests across Java and Python.

7. Not done yet (say honestly if asked)

  • No real bank linking (CSV instead). Credit score is simulated.
  • Docker setup written but not tested; we run it with run.sh.
  • Document search uses simple word matching (TF-IDF), not a neural embedding model.
  • Reminders are in-app only (no SMS/email). Tax covers salaried people under 60.
